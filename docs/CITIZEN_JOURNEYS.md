# Citizen Journeys

## Learner Licence

1. Use the demo login.
2. Open or resume Learner Licence from the dashboard.
3. Complete eligibility and mock identity (OTP `123456`).
4. Confirm prefilled personal details and add a fictional guardian name.
5. Enter a synthetic address, choose a demo RTO, and add three simulated documents.
6. Pick an appointment, review, declare, and complete the test payment.
7. The generated application opens in tracking with a clear next action.

Drafts save to localStorage after changes and restore after refresh. Validation keeps incomplete steps locked.
